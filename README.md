# checkn

Check if a name is a defined Python name

## Description

Tool to check if a name is defined Python name:
- A builtin class
- A builtin module
- A module in the standard libraries
- An installable library
- An installed library on the current system

## Getting Started

### Dependencies



### Installing

`pip install checkn`

### Executing program

`checkn <name>`
